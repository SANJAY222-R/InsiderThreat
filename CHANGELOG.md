# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [0.1.0] — Phase 0 — Architecture Scaffold

### Added
- Complete project directory structure (~192 files)
- Backend architecture (FastAPI, Clean Architecture)
- Frontend scaffold (React, TypeScript, Vite, TailwindCSS, Shadcn UI)
- AI module structure (PyTorch, PyG, THGNN stubs)
- Graph module structure (NetworkX, Neo4j, PyG exporters)
- Configuration management (Hydra, YAML configs)
- Centralized logging architecture (Loguru)
- Custom exception hierarchy
- Testing scaffold (PyTest, unit/integration/API/AI/graph)
- Docker deployment setup (multi-stage builds, Nginx, Compose)
- CI/CD pipelines (GitHub Actions)
- Comprehensive documentation templates
- Dataset metadata and schema definitions (CERT r4.2)
- Developer tooling (.editorconfig, Makefile, linters)
